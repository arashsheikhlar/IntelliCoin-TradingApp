# **IntelliCoin: a mobile app for trading crypto with AI recommendations**

Description
--------------
This application offers a Python and Kivy-based Cross Platform Mobile App that serves as a Crypto Portfolio and Trade Suggestion tool.
To make a run this software, follow these steps:
First, make sure that you have installed Python 3 (or above) and kivy on your machine, as follows:
```
sudo apt-get update
sudo apt-get install python3.6
python -m pip install kivy
```
It is recommended to use Pycharm IDE (or Visual Studio). Then, clone the app to your machine or download the zip file and extract its contents. Navigate to the directory where the files were downloaded. You should install the requirements as follows
```
python -m pip install -r requirements.txt
```
> **Pro-tip**:
> To enhance package management, it is recommended to employ a virtual environment.
 Lastly, execute the app by emulating it as a mobile application using the following command:
```
python Main.py --size=300x640
```
You will get in the app's sign in window.
